Política de Privacidad

Última actualización: 2026

En TRUE LOCK nos comprometemos a proteger la información de los usuarios y a utilizarla únicamente para las funciones necesarias del proyecto. Esta política explica de manera sencilla qué información puede ser utilizada, para qué se utiliza y cómo se maneja dentro de la plataforma.

1. Información que podemos utilizar

Dependiendo de las funciones utilizadas, TRUE LOCK puede manejar información proporcionada directamente por el usuario.

También pueden generarse datos relacionados con el uso de la plataforma.

2. Uso de la información

La información utilizada por TRUE LOCK puede ser necesaria para permitir el acceso y funcionamiento de las cuentas.

3. Información relacionada con páginas y aplicaciones

Debido a la finalidad de TRUE LOCK, el sistema puede trabajar con información relacionada con páginas web, aplicaciones y controles establecidos por los administradores.

Esta información se utiliza para permitir el funcionamiento de las restricciones y herramientas de control del sistema.

4. Almacenamiento de la información

La información puede almacenarse de forma local o en los sistemas utilizados para el funcionamiento de TRUE LOCK.

5. Protección de la información

TRUE LOCK busca mantener medidas de seguridad adecuadas para proteger la información manejada por la plataforma.

Por esta razón, recomendamos mantener las credenciales de acceso protegidas.

6. Compartir información

TRUE LOCK no tiene como finalidad vender ni intercambiar información personal de los usuarios.

La información podrá ser utilizada por las personas autorizadas para administrar el sistema.

7. Almacenamiento local y preferencias

El sitio web puede utilizar almacenamiento local del navegador para guardar determinadas preferencias del usuario.

Estos datos permiten que el sitio recuerde determinadas opciones cuando el usuario vuelve a utilizarlo.

8. Enlaces externos

El sitio web de TRUE LOCK puede contener enlaces hacia otros sitios o servicios.

Recomendamos revisar las políticas de privacidad de cualquier sitio externo.

9. Derechos del usuario

El usuario puede solicitar información sobre los datos que se estén utilizando dentro de TRUE LOCK.

Las solicitudes relacionadas con la información personal podrán realizarse mediante los canales de contacto.

10. Cambios en esta política

Esta política puede actualizarse cuando se incorporen nuevas funciones o cambios en TRUE LOCK.

Cuando se realicen cambios importantes, se actualizará la fecha indicada al inicio de esta página.

11. Contacto

Para realizar consultas relacionadas con esta política de privacidad o con el manejo de información dentro de TRUE LOCK, el usuario podrá utilizar los canales de contacto establecidos para el proyecto.
